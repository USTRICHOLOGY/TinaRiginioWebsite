# Tina Riginio Website

One-page site for Tina Riginio, Certified Clinical Trichologist at Bella Luna Salon.

Plain static site: no build step, no framework. Open `index.html` in a browser or deploy the folder as is (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

## Files

- `index.html`: the page
- `styles.css`: shared styles, the before and after reveal, and phone layout tweaks
- `script.js`: the hair growth cycle tabs and the before and after hover reveal
- `assets/`: hero image, Tina's portrait, favicon, and `before-after/` (8 pairs, `pN-before.jpg` / `pN-after.jpg`)
